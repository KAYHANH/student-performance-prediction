# 🎓 Student Performance Prediction System  
**Machine Learning–Based Academic Outcome Analysis**

**Tech Stack:** Python · scikit-learn · XGBoost · Pandas · NumPy · Matplotlib · Seaborn  

---

## 📌 About the Project

The **Student Performance Prediction System** is a machine learning project focused on predicting students’ academic outcomes based on demographic, socio-economic, and academic-related features. With the growing importance of data-driven decision-making in education, this project demonstrates how predictive analytics can be used to analyze large-scale student data and forecast academic performance.

The system is built using a dataset containing approximately **1 million student records** and follows a complete data science workflow, including data preprocessing, exploratory data analysis (EDA), model training, evaluation, and comparison. Multiple classification algorithms were implemented, with ensemble learning techniques showing superior performance.

---

## 📊 Dataset

- **Source:** Kaggle – Student Performance Dataset  
- **Size:** ~1,000,000 records  
- **Target Variable:** Grade

## 🎯 Project Overview

- Dataset: Student Performance Dataset (Kaggle)  
- Target Variable: Grade  
- Machine Learning Task: Multi-class Classification  

### Models Used
- Logistic Regression  
- Decision Tree Classifier  
- Random Forest Classifier  
- Gradient Boosting Classifier

---

## 📈 Results Summary

- **Best Performing Models:** Gradient Boosting / XGBoost  
- **Accuracy Achieved:** ~69.5%  
- **Evaluation Metrics:**
  - Accuracy  
  - F1-Score  
  - Confusion Matrix

## 📊 Exploratory Data Analysis (EDA)

Exploratory Data Analysis was conducted to understand feature distributions, identify correlations, detect potential class imbalance, and guide preprocessing and model selection. Visualizations were created using Matplotlib and Seaborn.
